# Slay the Curiosity - 游戏开发进度记录

这是一个基于《杀戮尖塔》机制开发的网页卡牌游戏。本项目已完成多项核心机制的深度改造，以下是当前版本的详细记录，方便跨账号接续开发。

## 🚀 当前已完成的核心功能

### 1. 角色系统：射手 (Archer) 深度重制
- **核心机制：蓄力 (Charge)**
  - 打出技能牌积累蓄力（上限5，可升级至8）。
  - 绝大多数攻击牌现在都与蓄力绑定：消耗全部蓄力，根据消耗点数获得高额伤害加成。
- **数值平衡**：
  - 基础 HP 设定为 60。
  - 削弱了基础防御牌的数值，强制玩家通过“蓄力-爆发”的节奏进行战斗。
- **HUD 修复**：修复了射手在获得蓄力时手牌 DOM 异常消失的 Bug，现在蓄力数字通过独立的 `archer-charge-hud` 实时更新。

### 2. 卡牌升级系统 (Card Upgrade System)
- **双重升级**：每张卡牌现在支持两次升级（+1 和 +2）。
- **升级预览**：在卡牌详情弹窗中，玩家可以清晰看到两次升级分别带来的数值提升或效果改变。
- **覆盖范围**：已完成赛车手 (Racer) 和射手 (Archer) 两个角色共 40 张卡牌的升级数据配置。

### 3. 交互体验改造
- **商店交互**：改为“单击查看详情，双击购买”，防止误触。
- **牌堆交互**：局内摸牌堆、弃牌堆改为“双击查看详情”。
- **详情弹窗**：统一了卡牌详情的 Overlay 展示，支持显示品质、类型、费用及升级预览。

### 4. 地图节点：市井 (Market)
- **视觉修复**：背景已从“营地绿色”改为“市井暖色调”。
- **新增功能：学习 (Learn)**
  - 玩家在市井节点可以选择“学习”选项。
  - 弹出牌组界面，允许玩家选择一张卡牌进行升级（最高 2 级）。

## 📂 文件结构说明
- `game.js`: 核心逻辑，包含所有卡牌定义、战斗引擎、UI 渲染及升级数据。
- `game.css`: 样式表，包含所有界面布局、卡牌特效及市井背景样式。
- `index.html` / `game.html`: 游戏入口。
- `upgrade_design.md`: 原始升级方案设计文档。
