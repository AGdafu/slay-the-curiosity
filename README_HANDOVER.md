# 《Slay the Curiosity》项目交接文档

## 1. 项目概况
本项目是一款基于《杀戮尖塔》玩法的中文网页卡牌游戏。
- **技术栈**：纯原生 JavaScript + HTML + CSS（单文件架构 `game.js`）。
- **核心特色**：包含射手（Archer）、赛车手（Racer）、蛮力（Brute）三个各具特色的职业。

## 2. 当前开发进度 (截至 2026-04-28)
### 已完成功能：
- **全职业基础构建**：三个职业的卡牌、遗物、升级系统均已完备。
- **赛车手 (Racer) 核心机制**：
    - 档位系统（1-3档，影响攻防倍率）。
    - 速度感系统（分段解锁强力 Buff，包含 UI 动画提示）。
    - 换挡动画与交互逻辑优化。
- **射手 (Archer) 核心机制**：
    - 蓄力系统（动态伤害显示，数值已平衡加强）。
- **蛮力 (Brute) 核心机制**：
    - 升级数据补全，战斗中升级效果实时生效。
- **事件系统**：还原了“善良的色环蜘蛛”问号事件。
- **遗物平衡性**：对大眼钉鞋、大头鼓棒、高山雪镜、王微系列遗物进行了数值调整。
- **移动端优化**：优化了双击灵敏度，支持 touchstart。

### 待办事项 / 未来方向：
- 增加更多关卡与怪物种类。
- 进一步丰富遗物池。
- 完善音效与视觉特效。

## 3. 技术架构说明
- **主逻辑文件**：`game.js` (约 4000+ 行)。
    - `Data.cards`: 卡牌定义。
    - `Data.upgrades`: 升级逻辑。
    - `State.run`: 存档状态。
    - `Combat`: 战斗核心逻辑（包含 `_changeGear` 等关键函数）。
    - `UI`: 渲染逻辑。
- **资源文件**：
    - `game.html`: 入口。
    - `spider.png`: 事件图片。

## 4. 给下一位开发者的建议
- **修改方式**：由于文件较大，建议使用 Python 脚本进行字符串替换修改，或直接编辑 `game.js`。
- **验证**：每次修改后运行 `node --check game.js` 确保无语法错误。
- **调试**：游戏状态存储在 `State.run` 中，可以通过控制台直接查看。
